Real-Time Chat App
Objective
Build a real-time chat app using Socket.io with Node.js backend and React frontend.

Features
Users can enter name and send messages
Messages broadcast in real-time to all connected clients
Handles user connection and disconnection
Simple, clean chat UI
How to Run
Backend
Navigate to backend
Run npm install
Start server: node index.js (runs on port 5000)
Frontend
Navigate to frontend
Run npm install
Start app: npm start (runs on port 3000)
Open multiple browser windows and chat in real-time
