React-Express-Axios Demo
Objective
Connect a React frontend application to a backend Express.js API using Axios to fetch and display product data.

How to Run
Backend
Navigate to backend folder.
Run npm install.
Start server: node index.js.
Server runs on http://localhost:5000.
Frontend
Navigate to frontend folder.
Run npm install.
Start app: npm start.
React app runs on http://localhost:3000 and fetches products from backend.
Features
Axios used for HTTP requests
Loading and error handling
Simple product list display
